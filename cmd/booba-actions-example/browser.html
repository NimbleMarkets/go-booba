Tap More for navigation, then Open. The controls change to Confirm and Back. Use Hide TUI help / Show TUI help to choose whether help also appears inside the terminal. Use Keyboard for normal typing.

Actions arrive through OSC 7501 terminal output. Buttons send ordinary keystrokes back. The marked JSON suffix in the status message is a private, opt-in convention.
